UDP reception with kernel receive timestamps.

Receiver reads batches of datagrams with one system call and reports each datagram’s host receive time. On Linux the time comes from the kernel SO_TIMESTAMPNS control message, taken when the datagram enters the network stack, so it does not depend on when the application gets to read the socket. Datagrams without a kernel timestamp are stamped with the clock read right after the receive call.
