pub fn update(&mut self, slice: &[u8]) -> Result<bool, Error>

Process a UDP packet, accumulating data into internal buffers.

Returns Ok(true) when a frame boundary is detected (new frame_id), meaning the previous frame’s data is complete and ready for processing.

§Zero-Copy Design

The depth and reflect buffers are owned by FrameReader and never copied. After this returns true, call depth() and reflect() to get references to the completed frame data, then call start_new_frame() to prepare for the next frame.

Source

pub fn update_at(&mut self, slice: &[u8], rx_ns: u64) -> Result<bool, Error>

Same as update for a packet received at rx_ns nanoseconds since the Unix epoch.

pub fn start_new_frame(&mut self)

Start a new frame after the previous one has been consumed.

This clears the buffers and resets the frame_ready flag.

Sensor timestamp of the current/completed frame’s first valid column in nanoseconds. It is in the host clock domain only when the sensor is in TIME_FROM_PTP_1588 mode and synchronized.
